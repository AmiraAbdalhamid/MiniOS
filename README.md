# MiniOS





Java desktop app with a graphical interface and a terminal that simulates core OS concepts
CPU scheduling: Round Robin, SJF, and Priority
Memory management: paging and segmentation, with a RAM view
Page replacement: FIFO, LRU, MRU, OPT, and Clock
Disk scheduling: FCFS, SSTF, SCAN, C-SCAN, LOOK, and C-LOOK
Uses an MVC structure, with separate Controller, Model, and UI packages
